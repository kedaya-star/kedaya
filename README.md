# Snack Racer

A simple Pygame-based racing game where you control an orange snack and dodge oncoming red cars. The game displays the distance traveled.

## Requirements
- Python 3
- [pygame](https://www.pygame.org/)

Install dependencies:
```bash
pip install pygame
```

## Run
```bash
python main.py
```
Use arrow keys to move. Avoid red cars and watch your distance grow!
